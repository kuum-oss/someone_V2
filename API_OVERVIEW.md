# Техническая документация API (Пример) — someone

Данный документ описывает внутренние или гипотетические эндпоинты системы для интеграции с другими сервисами или для внутреннего использования в будущем.

## Основные сведения
- **Базовый URL**: `http://localhost:8080/api/v1`
- **Формат обмена данными**: JSON
- **Кодировка**: UTF-8

## Эндпоинты

### 1. Получение информации о книге по ISBN
Используется для получения детальной информации о книге из внешних источников (например, Google Books).

- **URL**: `/books/lookup/{isbn}`
- **Метод**: `GET`
- **Параметры пути**:
  - `isbn` (string): 10 или 13-значный код ISBN.

**Пример запроса:**
`GET /api/v1/books/lookup/9780544003415`

**Пример ответа (200 OK):**
```json
{
  "title": "The Lord of the Rings",
  "author": "J.R.R. Tolkien",
  "genre": "Fantasy",
  "language": "en",
  "pageCount": 1178,
  "thumbnailUrl": "http://books.google.com/content?id=e_S8O3A..."
}
```

---

### 2. Регистрация нового пользователя
Создает новую учетную запись в локальной базе данных.

- **URL**: `/auth/register`
- **Метод**: `POST`
- **Тело запроса**:
```json
{
  "email": "user@example.com",
  "password": "securePassword123"
}
```

**Пример ответа (201 Created):**
```json
{
  "id": 42,
  "email": "user@example.com",
  "status": "success",
  "message": "User registered successfully"
}
```

---

### 3. Получение списка отсканированных книг
Возвращает список книг, которые были обработаны приложением.

- **URL**: `/library/books`
- **Метод**: `GET`

**Пример ответа (200 OK):**
```json
[
  {
    "id": 1,
    "title": "Преступление и наказание",
    "author": "Фёдор Достоевский",
    "format": "EPUB"
  },
  {
    "id": 2,
    "title": "1984",
    "author": "George Orwell",
    "format": "PDF"
  }
]
```

## Коды ответов и ошибок

| Код | Описание |
|-----|----------|
| 200 | Успешно |
| 201 | Ресурс успешно создан |
| 400 | Некорректный запрос (неверные параметры) |
| 401 | Ошибка авторизации (неверный логин/пароль) |
| 404 | Ресурс не найден |
| 500 | Внутренняя ошибка сервера |
