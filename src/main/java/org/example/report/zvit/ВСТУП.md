**Актуальність.** Сьогодні технології постійно розвиваються, не стоїть на місці й культура споживання контенту, зокрема електронних книг. Кожен розробник намагається зробити більш конкурентний продукт та показати свій товар з його можливостями потенційному клієнту, який у ньому зацікавлений.
В зв’язку з активним розвитком комп’ютерних технологій споживач частіше використовує інтернет для зберігання, пошуку та читання необхідних речей і цифрові книги не є виключенням із цього списку.
На практиці користувачі часто стикаються з проблемою хаотичного зберігання великої кількості файлів на різних пристроях, але користувач може дізнатися основні моменти на сайті або в додатку відповідного розробника, щоб знайти відповідне цифрове майно до своїх вподобань.
Клієнти мають намір зручно організувати власну бібліотеку і не завжди мають час особисто сортувати сотні файлів, щоб переглянути асортимент. Ця ситуація стимулює пошук нових підходів для представлення свого продукту. Одним із способів вирішення проблем клієнта з вибором та організацією є впровадження власного вебдодатку «Smart Organizer» для швидкого ознайомлення з ним споживачем.

**Об’єкт дослідження.** Процес автоматизації управління персональною цифровою бібліотекою та систематизації електронного контенту.

**Предмет дослідження.** Методи, алгоритми та інструментальні засоби розробки вебдодатку для організації, зберігання та доступу до електронних книг з використанням мови програмування Java.

**Мета курсового проєкту.** Отримати практичні навички з проєктування та розробки вебдодатку «Smart Organizer» (someone), який буде відповідати потребам теперішнього споживача відповідного продукту та зробить представлення товарів зрозумілим і конструктивним.

**Завдання.** Для досягнення поставленої мети необхідно вирішити наступні задачі:
 дослідити предметну область, зокрема особливості представлення та управління електронними бібліотеками та існуючі підходи до вебдодатків;
 визначити потреби та вимоги (функціональні та нефункціональні) щодо розробки веб-додатку Smart Organizer;
 вибрати відповідне програмне забезпечення, яке оптимально підходить для вирішення наших задач;
 розробити інформаційну модель та описати вхідні і вихідні дані;
 розробити функціональну модель системи;
 розробити структурний алгоритм роботи веб-додатка;
 спроєктувати архітектуру веб-додатка;
 спроєктувати базу даних для веб-додатка;
 спроєктувати користувацький інтерфейс для веб-додатка;
 скласти тест-кейси для перевірки вимог до веб-додатка;
 представити прототип готового рішення.

**Практичне значення одержаних результатів.** Полягає в тому, що розроблений вебдодаток може бути застосований користувачем для представлення та управління книгами в особистих цілях або як частина корпоративної бібліотечної системи.

**Інструментальні засоби.** При виконанні курсового проекту було використано такі інструментальні засоби:
 середовище програмування IntelliJ IDEA 2024.2.3 (Ultimate Edition);
 об’єктно-орієнтована мова програмування Java 21;
 фреймворк Javalin 6.1.3 для створення веб-сервера, бібліотека Apache Tika 2.9.2 для вилучення метаданих з файлів, бібліотека FlatLaf 3.4.1 для створення сучасного інтерфейсу;
 СУБД MySQL та інструмент MySQL Workbench 8.3 CE для проектування та керування базою даних;
 мова розмітки HTML 5 для створення вебсторінок та мова стилів CSS 3 для оформлення вебсторінок;
 динамічна об’єктно-орієнтована прототипна мова програмування JavaScript ES2024;
 операційна система macOS/Windows 10;
 текстовий редактор Microsoft Word 2021 для підготовки та оформлення пояснювальної записки до курсового проєкту;
 застосунок Microsoft PowerPoint 2021 для створення презентації;
 Docker та Docker Compose для контейнеризації та розгортання системи.
