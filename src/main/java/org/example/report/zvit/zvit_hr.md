# ПРОФЕСІЙНИЙ ТЕХНІЧНИЙ ПОРТФОЛІО: ПРОЕКТ "SMART ORGANIZER"
## Portfolio Case Study (Java Backend / Full Stack)

### Загальна інформація
**Проект:** Smart Organizer — повнофункціональна інформаційна система для управління цифровими та фізичними бібліотеками.
**Роль:** Java Developer / Software Architect.
**Технологічний стек:** Java 21, Maven, MySQL, Javalin (Web), Swing (GUI), FreeMarker, Apache Tika, JUnit 5, Mockito, FlatLaf, Docker.

---

### 1. Архітектурні рішення та проектування
При розробці системи було застосовано принципи **Clean Architecture** (Чиста архітектура) Роберта Мартіна, що забезпечило:
- **Незалежність від фреймворків:** Ядро системи (Core) містить лише бізнес-логіку та не залежить від зовнішніх бібліотек або баз даних.
- **Розділення відповідальності:** Чіткий розподіл на шари (Entities -> Use Cases -> Adapters -> Infrastructure).
- **Використання паттернів:** Реалізовано паттерни **Builder** (для сутностей), **Dependency Injection** (через конструктори), **Repository** (для доступу до даних) та **Adapter**.

---

### 2. Ключові технічні компетенції

#### Backend Development (Java)
- **Робота з даними:** Проектування реляційної моделі БД (MySQL), реалізація шару доступу до даних (JDBC) з використанням пулу з'єднань (Apache DBCP2).
- **Обробка файлів:** Інтеграція Apache Tika для автоматичного вилучення складних метаданих (автор, назва, мова) з файлів форматів PDF, EPUB, FB2.
- **Безпека:** Реалізація авторизації через сесії, шифрування паролів за допомогою BCrypt, впровадження Rate Limiting та захисту від CSRF.

#### Web & GUI Development
- **Web:** Створення легковажного веб-сервера на Javalin, використання шаблонізатора FreeMarker для динамічного рендерингу контенту.
- **Desktop:** Розробка настільного інтерфейсу на Swing з використанням сучасного дизайну (FlatLaf) та підтримкою темної теми.
- **UX/UI:** Забезпечення однакового функціоналу як у веб-версії, так і в настільному додатку.

#### DevOps & Quality Assurance
- **Docker:** Контейнеризація додатку, написання `docker-compose.yml` для швидкого розгортання связки додаток + база даних.
- **Тестування:** Покриття критичної бізнес-логіки Unit-тестами (JUnit 5, Mockito), використання ArchUnit для автоматичної перевірки архітектурних правил.
- **Оптимізація:** Впровадження асинхронного сканування файлів та кешування обкладинок (Thumbnail Cache) для підвищення продуктивності.

---

### 3. Проектний менеджмент та Soft Skills
- **Документування:** Створення детальної технічної документації (`admin.md`, `API_OVERVIEW.md`) та інструкцій для користувачів (`USER_GUIDE.md`).
- **Самостійність:** Повний цикл розробки — від ідеї та проектування БД до фінального тестування та деплою.
- **Аналітичне мислення:** Вирішення складних завдань, таких як автоматична нормалізація імен файлів та управління хмарним сховищем безпосередньо в БД через BLOB.

---

### 4. Основні результати
- Створено продукт, готовий до масштабування та промислової експлуатації.
- Реалізовано гнучку систему замовлень та сповіщень.
- Досягнуто високої чистоти коду, що значно полегшує його підтримку та розширення.

**Висновок:** Даний проект демонструє мою здатність будувати складні системи "з нуля", дотримуватися високих стандартів розробки та ефективно використовувати сучасний інструментарій Java-екосистеми.
