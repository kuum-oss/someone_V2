# ТЕХНІЧНИЙ ЗВІТ: НАЛАШТУВАННЯ СЕРЕДОВИЩА РОЗРОБКИ ТА ІНФРАСТРУКТУРИ
## Проект "Smart Organizer"

### Загальна інформація
**Тема:** Підготовка інструментарію та конфігурація серверних компонентів для розробки ІС.
---

### 1. Огляд технологічного стеку та теоретична підготовка
Для реалізації проекту було обрано сучасний стек технологій, що забезпечує стабільність та продуктивність:
- **Java 21 (LTS):** Використання останніх можливостей мови (Virtual Threads, Pattern Matching).
- **СУБД MySQL:** Надійне реляційне сховище для метаданих та контенту.
- **Maven:** Професійне управління залежностями та збіркою проекту.
- **Clean Architecture:** Методологія розділення бізнес-логіки та інфраструктури.

---

### 2. Налаштування IDE IntelliJ IDEA
Процес конфігурації середовища розробки включав:
- **Встановлення JDK 21:** Налаштування SDK проекту для підтримки сучасного синтаксису.
- **Плагіни:** Встановлення та налаштування плагінів для роботи з Maven, Database Navigator (для SQL запитів) та Checkstyle (для контролю якості коду).
- **Конфігурація Run/Debug:** Створення профілів запуску для GUI та Web режимів, налаштування VM-аргументів для коректної обробки кодування UTF-8.

---

### 3. Конфігурація MySQL Server
Для розгортання серверної частини бази даних:
- **Інсталяція:** Встановлено та налаштовано MySQL Server версії 8.0+.
- **Безпека:** Створено окремого користувача з обмеженими правами для доступу додатка до конкретної схеми даних.
- **Оптимізація:** Налаштовано системну змінну `max_allowed_packet` (64MB) для забезпечення можливості передачі великих BLOB-об'єктів (файлів книг).

---

### 4. Робота з MySQL Workbench
Для візуального проектування та управління базою даних використано MySQL Workbench:
- **ER-діаграми:** Спроектовано логічну модель даних, визначено зв'язки між таблицями `users`, `books` та `orders`.
- **SQL Execution:** Перевірено скрипти ініціалізації структури таблиць.
- **Моніторинг:** Налаштовано інструменти відстеження активних з'єднань та продуктивності запитів.

---

### 5. Результати налаштування (Візуальний аналіз)
Нижче представлено опис ключових елементів налаштованої системи:
- **Структура проекту в IDEA:** Чіткий поділ на пакети (`core`, `adapter`, `infrastructure`), що підтверджує готовність середовища до розробки згідно з Clean Architecture.
- **Статус сервера:** Підтверджено успішне підключення до MySQL через вбудовані інструменти IDEA та Workbench.
- **Ініціалізація даних:** Первинна схема даних успішно розгорнута, що дозволяє системі функціонувати в автономному режимі.

---

### Висновки
Етап підготовки середовища завершено успішно. Налаштована інфраструктура (IDE + СУБД) відповідає професійним стандартам розробки. Використання MySQL Workbench значно спростило процес проектування моделі даних, а правильна конфігурація IntelliJ IDEA забезпечує високу швидкість розробки та зручність налагодження коду.
