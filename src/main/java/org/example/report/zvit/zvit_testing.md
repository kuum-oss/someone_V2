### Реалізація (Фрагмент Unit-тесту)
```java
package org.example.core.usecase;

import org.example.core.entity.Book;
import org.junit.jupiter.api.Test;
import org.mockito.Mockito;
import static org.junit.jupiter.api.Assertions.*;
import static org.mockito.Mockito.when;

/**
 * Перевіряє сценарій вилучення метаданих за допомогою моків.
 */
class ExtractMetadataUseCaseTest {
    @Test
    void shouldExtractMetadataFromLocalGateway() {
        Path path = Paths.get("test.fb2");
        Map<String, String> rawMd = new HashMap<>();
        rawMd.put("dc:title", "Test Title");

        // Налаштування поведінки заглушки
        when(metadataGateway.extractRawMetadata(path)).thenReturn(rawMd);

        Book book = useCase.execute(path);

        assertEquals("Test Title", book.getTitle());
    }
}
```

### Впроваджені оптимізації
1. **Thumbnail Cache:** Система зберігає згенеровані обкладинки на диску, уникаючи повторної обробки великих зображень.
2. **Async Scanning:** Використання фонових потоків для Apache Tika дозволяє GUI залишатися чуйним під час імпорту великих колекцій.
3. **Database Pooling:** Apache DBCP2 мінімізує затримки при зверненні до MySQL.
4. **Rate Limiting:** Захист веб-сервера від DoS-атак та автоматизованих скриптів.
