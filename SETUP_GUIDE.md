# Руководство по установке и запуску — someone

В данном документе описаны шаги, необходимые для подготовки среды и запуска приложения **someone** в различных режимах.

## Системные требования
Для работы приложения вам понадобятся следующие инструменты:
- **Java Development Kit (JDK) версии 21** или выше.
- **Apache Maven** (для сборки проекта из исходного кода).
- **Docker & Docker Compose** (для быстрого развертывания).
- **MySQL 8.3** (если планируете запускать базу данных отдельно).
- **Интернет-соединение** (необходимо для получения метаданных из Google Books).

## Варианты запуска

### Вариант 1: Через Docker (рекомендуется)
Это самый простой способ, так как все зависимости (включая базу данных) настроены автоматически.

1. Убедитесь, что Docker запущен.
2. Выполните команду в корне проекта:
   ```bash
   docker-compose up --build
   ```
3. Приложение соберется и запустится в режиме **Web-сервера**.
4. Откройте браузер и перейдите по адресу: `http://localhost:8080`

### Вариант 2: Локальный запуск (GUI или Web)
Если вы хотите использовать десктопный интерфейс с функцией Drag & Drop:

1. **Сборка проекта**:
   ```bash
   mvn clean package -DskipTests
   ```
2. **Запуск**:
   ```bash
   java -jar target/someone-1.0-SNAPSHOT.jar
   ```
3. **Выбор режима**:
   При запуске появится окно с выбором:
   - **Приложение (GUI)**: Полноценный интерфейс для организации книг.
   - **Сайт (Web)**: Запуск локального сервера и открытие библиотеки в браузере.

## Настройка базы данных
Приложение использует MySQL. Если вы запускаете его не через Docker, убедитесь, что параметры подключения в `src/main/resources/application.properties` верны:
- `db.url`: адрес сервера MySQL.
- `db.user`: имя пользователя.
- `db.password`: пароль.

**Примечание**: Приложение обладает системой "самоисцеления" — оно само создаст базу данных `library_db` и все необходимые таблицы при первом запуске.

## Самоисцеление и порты
- **Порты**: Если стандартный порт `8080` занят, приложение автоматически найдет свободный порт и сообщит об этом.
- **База данных**: Если MySQL еще не готов (например, при старте контейнера), приложение сделает 5 попыток подключения с интервалом в 3 секунды.

## Устранение неполадок
1. **Ошибка порта 8080**: Если вы видите сообщение, что порт занят, просто подождите — приложение найдет другой порт или попробуйте остановить другие Docker-контейнеры.
2. **Проблемы с БД**: Проверьте, запущен ли MySQL и верны ли доступы в `application.properties`.
3. **Отсутствие обложек**: Убедитесь, что у приложения есть доступ к интернету для связи с API Google Books.
