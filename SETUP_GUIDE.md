# Руководство по установке и запуску — someone

В данном документе описаны шаги, необходимые для подготовки среды и запуска приложения **someone**.

## Системные требования
Для работы приложения вам понадобятся следующие инструменты:
- **Java Development Kit (JDK) версии 21** или выше.
- **Apache Maven** (для сборки проекта из исходного кода).
- **Браузер** (для регистрации в системе и доступа к внешним ресурсам).
- **Интернет-соединение** (необходимо для получения метаданных из Google Books и загрузки иконок жанров).

## Шаги по установке

### 1. Клонирование репозитория
Если у вас есть доступ к исходному коду, клонируйте репозиторий:
```bash
git clone https://github.com/kuum-oss/someone.git
cd someone
```

### 2. Сборка проекта
Используйте Maven для компиляции и сборки исполняемого JAR-файла:
```bash
mvn clean package -DskipTests
```
После завершения в папке `target` появится файл `someone-1.0-SNAPSHOT.jar`.

### 3. Создание аккаунта
При первом запуске приложения вам потребуется создать локальный аккаунт:
- Введите ваш Email.
- Придумайте пароль.
- Эти данные будут храниться локально в вашей базе данных.

## Запуск приложения
Для запуска используйте команду:
```bash
java -jar target/someone-1.0-SNAPSHOT.jar
```

## Перепроверка работы
Чтобы убедиться, что всё работает правильно, проверьте следующие пункты:
1. **Окно авторизации**: После запуска должно появиться окно входа/регистрации.
2. **Главное окно**: После входа должно открыться основное окно со светлой или темной темой (в зависимости от настроек системы).
3. **Загрузка иконок**: В нижней части или в меню должны отображаться иконки жанров (если есть интернет).
4. **Логи**: В консоли не должно быть критических ошибок (Exception) при старте.

Если вы видите главный интерфейс и можете перетащить в него файл книги — значит, система запущена успешно!
