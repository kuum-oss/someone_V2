# Будущие обновления и улучшения проекта (Fut.md)

Проект представляет собой мощную платформу для управления библиотекой с гибридным интерфейсом (Swing + Web). На основе анализа архитектуры и функционала, предложены следующие направления развития:

### 1. Архитектурные и технические улучшения
- **Разделение монолитного UI**: Класс `BookLibraryGui.java` содержит более 1600 строк. Необходимо выделить логику обработки событий в отдельные контроллеры или презентеры (паттерны MVP или MVVM).
- **Миграция на полноценный ORM**: В текущий момент используется JDBC в инфраструктурном слое. Переход на **Hibernate** или **Spring Data JPA** (при переходе на Spring Boot) упростит работу с БД и обеспечит типобезопасность.
- **Интеграция Spring Boot**: Проект использует отдельные библиотеки (Javalin, Jackson, Tika). Переход на Spring Boot позволит стандартизировать конфигурацию, внедрение зависимостей и упростит масштабирование веб-части.
- **Кэширование**: Внедрение кэша (например, **Redis** или **Caffeine**) для обложек книг и метаданных, чтобы снизить нагрузку на БД и ускорить отрисовку списка.
- **Модульное тестирование**: Покрытие `core` и `usecase` слоев тестами достигает хорошего уровня, но необходимо добавить интеграционные тесты для БД с использованием **Testcontainers**.

### 2. Улучшения пользовательского интерфейса (UI/UX)
- **Адаптивный Web-интерфейс**: Текущие шаблоны Freemarker выглядят аккуратно, но требуют доработки для мобильных устройств.
- **Анимации в Swing**: Использование библиотеки `FlatLaf` позволяет внедрить плавные переходы и более современные визуальные эффекты.
- **Полнотекстовый поиск**: Интеграция **Apache Lucene** или **Elasticsearch** для поиска не только по названиям, но и по содержанию книг (особенно актуально для PDF/TXT).
- **Темная тема**: Автоматическое переключение темы в зависимости от настроек системы (через FlatLaf).

### 3. Функциональные нововведения
- **Поддержка аудиокниг**: Добавление плеера в Swing и Web интерфейсы для прослушивания аудиофайлов.
- **Встроенная читалка (PDF/EPUB)**: Сейчас приложение предлагает "открыть файл", но наличие встроенного просмотрщика (через `ICEpdf` для Java или `PDF.js` для Web) значительно улучшит UX.
- **Социальные функции**:
  - Система рейтингов и развернутых отзывов с модерацией.
  - Списки "Хочу прочитать" и "Прочитано".
  - Возможность обмена книгами (Bookcrossing) через физический магазин.
- **Интеграция с внешними API**: Автоматическое скачивание обложек и описаний через **Google Books API** или **Open Library API** при добавлении новой книги.
- **Система достижений**: Геймификация процесса чтения (баллы за количество прочитанных страниц, бонусы за отзывы).

### 4. Инфраструктура и безопасность
- **Docker-оптимизация**: Сейчас Docker используется для MySQL. Стоит создать multi-stage сборку для самого приложения, чтобы разворачивать Web-сервер в один клик.
- **Безопасность**:
  - Внедрение **JWT** для веб-авторизации вместо простых сессий.
  - Двухфакторная аутентификация (2FA).
- **Облачное хранилище**: Поддержка хранения файлов в **AWS S3** или **Google Cloud Storage** вместо хранения `LONGBLOB` в базе данных (что сильно раздувает размер БД).

### 5. Локализация и доступность
- **Расширение языковой поддержки**: Добавление большего количества языков (не только ru/uk/en).
- **Поддержка Screen Readers**: Оптимизация Swing-компонентов для людей с ограниченными возможностями.
