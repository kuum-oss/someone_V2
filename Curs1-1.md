# 11. Проєктування та розробка користувацького інтерфейсу

У цьому розділі описано проектування інтерфейсу користувача для системи управління, яка реалізована як гібридний додаток: повноцінний веб-сайт та десктопний GUI-інтерфейс (Swing).

## 1) Елементи інтерфейсу

Для побудови користувацького інтерфейсу були використані сучасні веб-технології, зокрема HTML5 та CSS3 з використанням FreeMarker шаблонів для динамічного відображення даних.

Основні використані елементи:
- **HTML Form elements (TextBox/Input)**: `<input type="text">`, `<input type="email">`, `<input type="password">` — використовуються для введення користувачем логіна (email), пароля, а також пошукових запитів.
- **Button (Кнопка)**: `<button type="submit">` та теги `<a>` з CSS-класами кнопок — для виконання ключових дій: "Увійти", "Зберегти", "Зареєструватися".
- **Label (Мітка)**: Елемент `<label>` — використовується для підписів до полів вводу, що забезпечує зрозумілість форми.
- **Div / Containers**: Використовуються `<div>` з Flexbox/Grid для структурування форм, створення карток (cards), контейнерів сторінок та навігації.
- **Links (Посилання)**: Теги `<a>` — для навігації між сторінками сайту.

## 2) Прототипи основних сторінок

Нижче наведено опис структури головних сторінок системи. Оскільки інтерфейс веб-орієнтований, прототипування виконувалося безпосередньо в коді HTML/CSS.

### Форма входу (Login)
Структура:
- Центрована картка (card) на екрані.
- Заголовок "Вхід в систему".
- Поля вводу (Email, Пароль).
- Кнопка "Войти".
- Посилання "Зареєструватися" для переходу до форми реєстрації.

### Головна сторінка
Структура:
- Навігаційна панель (header) з логотипом та посиланнями на основні розділи (наприклад, магазин, профіль, адмін-панель).
- Основний контентний блок, що адаптується під розмір екрану.

## 3) Реалізація екранних форм

Інтерфейс інтегрований у програму за допомогою FreeMarker шаблонів, які рендеряться на стороні сервера.

### Приклад коду форми входу (login.ftl)

Даний фрагмент показує створення елементів введення та обробку подій (відправка форми):

```html
<form action="/login" method="POST">
    <!-- Поле введення Email -->
    <div style="margin-bottom: 1rem;">
        <label>Email:</label>
        <input type="email" name="email" required placeholder="example@mail.com">
    </div>

    <!-- Поле введення Пароля -->
    <div style="margin-bottom: 1.5rem;">
        <label>Пароль:</label>
        <input type="password" name="password" required>
    </div>

    <!-- Кнопка відправки -->
    <button type="submit">Войти</button>
</form>
```

### Логіка стилізації (layout.ftl)

Для розміщення елементів та створення вигляду було використано CSS. Основна логіка навігації:

```css
header {
    background-color: rgba(17, 24, 39, 0.95);
    padding: 0.75rem 0;
    display: flex;
    justify-content: space-between;
}

.btn {
    display: inline-flex;
    padding: 0.7rem;
    border: none;
    border-radius: 8px;
    cursor: pointer;
}
```

Кожна форма (логін, реєстрація, деталі книги) успадковує загальний макет через `layout.ftl`, що забезпечує єдиний стиль (використання CSS-змінних, шрифтів та відступів).

## 4) Опис інтерфейсу користувача (веб та десктоп)

### Веб-версія
Система має розвинену веб-частину, яка налічує близько 15 основних сторінок та компонентів (шаблонів `.ftl`). Навігація в веб-версії побудована навколо єдиної верхньої панелі (header), яка забезпечує швидкий доступ до основних функцій (магазин, бібліотека, профіль користувача) з будь-якої сторінки додатку, забезпечуючи інтуїтивне переміщення користувача між розділами.

### Десктопна версія (Swing)
Проект також містить повноцінний десктопний інтерфейс, реалізований на технології Java Swing. Основний клас інтерфейсу — `BookLibraryGui`, який розширює `JFrame`. Ця реалізація надає користувачам альтернативний спосіб взаємодії з системою, включаючи:
- Деревовидну структуру відображення книг.
- Обробку гарячих клавіш та контекстних меню.
- Підтримку зміни тем та локалізацій.
- Повноцінну інтеграцію з бізнес-логікою програми (авторизація, робота з бібліотекою, покупки).

## 5) Тестування системи

Для забезпечення надійності та коректності роботи системи «Бібліотека книг» було розроблено набір тест-кейсів, які покривають як бізнес-логіку, так і взаємодію з даними:

- **Тест-кейс для перевірки реєстрації/авторизації користувача:** Перевірка коректності створення та отримання користувачів через `JdbcUserRepositoryIntegrationTest`.
- **Тест-кейс для перевірки управління книгами:** Перевірка операцій CRUD (створення, читання, оновлення, видалення) у базі даних через `JdbcBookRepositoryIntegrationTest`.
- **Тест-кейс для перевірки метаданих:** Тестування коректності видобування метаданих з книг (`ExtractMetadataUseCaseTest`).
- **Тест-кейс для організації бібліотеки:** Перевірка логіки групування та організації книг у сховищі (`GroupBooksUseCaseTest`, `OrganizeBooksUseCaseTest`).
- **Тест-кейс для обробки тексту:** Перевірка нормалізації введених даних через `TextNormalizerTest`.
- **Тест-кейс для архітектурних обмежень:** Перевірка дотримання шарів системи за допомогою `ArchitectureGuardTest`.
