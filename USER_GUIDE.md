# Руководство пользователя — someone

Добро пожаловать в **someone** — ваш персональный помощник в организации электронной библиотеки.

## Начало работы
Для начала работы с приложением выполните следующие шаги:

1. **Запуск**: Откройте приложение (инструкции по запуску в [SETUP_GUIDE.md](SETUP_GUIDE.md)).
2. **Авторизация**: При первом запуске вам будет предложено войти в систему или зарегистрироваться. Это необходимо для сохранения ваших настроек и доступа к библиотеке.
3. **Импорт книг**:
   - Перетащите папку с книгами или отдельные файлы прямо в окно приложения (Drag & Drop).
   - Приложение автоматически начнет сканирование и извлечение метаданных.
4. **Просмотр библиотеки**: Книги будут отображены в виде дерева, сгруппированного по языку, жанру и серии.

## Интерфейс
Интерфейс приложения интуитивно понятен и состоит из нескольких областей:

- **Панель дерева (слева)**: Позволяет перемещаться по категориям вашей библиотеки.
- **Список книг (центр)**: Отображает книги в выбранной категории.
- **Панель деталей (справа)**: Показывает подробную информацию о выбранной книге: обложку, автора, серию и аннотацию.
- **Верхнее меню**: Здесь можно сменить язык (RU/EN/UK) или тему оформления (Светлая/Темная).

## Организация библиотеки
После того как книги были отсканированы, вы можете нажать кнопку **"Organize into folders"**.
1. Выберите папку, где вы хотите создать структурированную библиотеку.
2. Приложение создаст папки по структуре: `Язык / Жанр / Серия / Файл_книги`.
3. Все файлы будут аккуратно скопированы в новые места.

## FAQ (Часто задаваемые вопросы)

**В: Какие форматы файлов поддерживает приложение?**
О: На данный момент поддерживаются `.pdf`, `.epub`, `.fb2` и `.mobi`.

**В: Откуда приложение берет обложки и жанры?**
О: Сначала приложение пытается извлечь данные непосредственно из файла книги. Если их там нет, оно обращается к сервису Google Books API.

**В: Могу ли я изменить метаданные вручную?**
О: В текущей версии автоматизация является приоритетом, поэтому редактирование вручную ограничено, но планируется в будущих обновлениях.

**В: Где хранятся мои данные?**
О: Приложение использует локальную базу данных для хранения информации о ваших книгах и учетной записи пользователя.
