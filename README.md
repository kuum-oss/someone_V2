### О проекте
**someone** — это десктопное приложение на Java (Swing + FlatLaf), предназначенное для автоматизации управления вашей коллекцией электронных книг. Проект решает проблему хаоса в локальных файлах, автоматически сканируя их, извлекая метаданные и организуя в четкую структуру папок.

### Основные функции
- **Автоматическое сканирование**: Просто перетащите папку с книгами в приложение (Drag & Drop).
- **Извлечение метаданных**: Автоматическое определение названия, автора, языка и серии книги (используя Apache Tika).
- **Интеграция с Google Books**: Подгрузка недостающих данных, жанров и обложек из сети.
- **Умная организация**: Автоматическое распределение файлов по папкам вида `Язык / Жанр / Серия / Название`.
- **Поддержка форматов**: Работа с популярными форматами `.pdf`, `.epub`, `.fb2`, `.mobi`.
- **Многопользовательский доступ**: Система регистрации и входа для управления персональной библиотекой.
- **Гибкий интерфейс**: Поддержка светлой и темной тем, а также мультиязычность (RU/EN/UK).

### Для кого этот продукт
Этот продукт идеально подходит для:
- **Заядлых читателей**, у которых скопились тысячи файлов книг в одной папке.
- **Коллекционеров**, желающих иметь идеально структурированную библиотеку с обложками и метаданными.
- **Пользователей**, предпочитающих локальное хранение книг облачным сервисам, но нуждающихся в удобном поиске и каталогизации.

### Требования
- **Java 21**
- **Maven** (для сборки)
- Подключение к интернету (для загрузки данных из Google Books)

### Быстрый запуск
1. Соберите проект: `mvn clean package -DskipTests`
2. Запустите: `java -jar target/someone-1.0-SNAPSHOT.jar`

Подробности в [Инструкции по установке](SETUP_GUIDE.md) и [Руководстве пользователя](USER_GUIDE.md).
