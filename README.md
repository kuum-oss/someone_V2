### О проекте
**someone** — это универсальное решение для управления вашей коллекцией книг. Приложение сочетает в себе мощный десктопный клиент (Java Swing + FlatLaf) для организации файлов и современный веб-интерфейс (Javalin + FreeMarker) для доступа к библиотеке через браузер.

### Основные функции
- **Два режима работы**: Полнофункциональное GUI-приложение или легкий Web-сервер.
- **Автоматическое сканирование**: Просто перетащите папку с книгами в GUI-приложение (Drag & Drop).
- **Извлечение метаданных**: Автоматическое определение названия, автора, языка и серии книги (используя Apache Tika).
- **Интеграция с Google Books**: Подгрузка недостающих данных, жанров и обложек из сети.
- **Умная организация**: Автоматическое распределение файлов по папкам вида `Язык / Жанр / Серия / Название`.
- **Docker Ready**: Быстрое развертывание всей инфраструктуры (БД + Приложение) одной командой.
- **Система самоисцеления**: Автоматический подбор портов и повторные попытки подключения к БД.
- **Магазин и Поинты**: Система покупки книг и бронирования физических книг с выбором места и времени.
- **QR-коды и Email-уведомления**: Генерация уникальных SHA-256 QR-билетов для заказов в физ. магазине, отправка билетов на email (через SMTP) и их сохранение/скачивание в личном кабинете.
- **Админ-панель и Сканер QR**: Управление пользователями, статистика БД, уведомления и возможность сканирования QR-кодов или ввода номера заказа для выдачи книг.

### Для кого этот продукт
Этот продукт идеально подходит для:
- **Заядлых читателей**, у которых скопились тысячи файлов книг.
- **Коллекционеров**, желающих иметь идеально структурированную библиотеку с обложками и метаданными.
- **Пользователей**, которым нужен доступ к своей библиотеке с разных устройств через браузер.

- **MySQL 8.3** (если запуск без Docker)

### Быстрый запуск

#### С помощью Docker (рекомендуется)

##### Режим веб-сайта (Web Server)
```bash
docker-compose up --build
```
После запуска сайт будет доступен по адресу: `http://localhost:8080`

##### Режим интерфейса (GUI / Swing App)
Для запуска GUI-приложения в контейнере (экран транслируется прямо в ваш браузер):
```bash
docker-compose -f docker-compose.gui.yml up --build
```
После запуска откройте в браузере страницу: `http://localhost:6080/vnc.html`

> **Как добавить книги в контейнере**
> Drag & drop через браузер не работает — файловая система контейнера изолирована от хоста. Положите книги в папку на хосте и примонтируйте её через volume в `docker-compose.gui.yml`:
> ```yaml
> app-gui:
>   volumes:
>     - ~/Books:/root/Books
> ```
> После этого в диалоге "Add Books" перейдите в `/root/Books` — там будут ваши файлы.

#### Локальный запуск
1. Соберите проект: `mvn clean package -DskipTests`
2. Запустите: `java -jar target/someone-1.0-SNAPSHOT.jar`
3. При запуске выберите режим: **Приложение (GUI)** или **Сайт (Web)**.

Подробности в [Инструкции по установке](SETUP_GUIDE.md) и [Руководстве пользователя](USER_GUIDE.md).
