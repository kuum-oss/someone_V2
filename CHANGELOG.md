# Журнал изменений (CHANGELOG) — someone

Все заметные изменения в этом проекте будут документироваться в этом файле.
//Точные даты неизвестны, также их периоды. 

## [1.2.0] - 2026-01-20
### Добавлено
- Создана расширенная русскоязычная документация (`README.md`, `USER_GUIDE.md`, `SETUP_GUIDE.md`, `API_OVERVIEW.md`).
- Улучшена структура документации для новых пользователей.
- Добавлены примеры API для будущих интеграций.

## [1.1.0] - 2026-01-10
### Добавлено
- Реализована система авторизации пользователей (вход и регистрация).
- Добавлена поддержка хранения данных в локальной базе данных.
- Внедрено шифрование паролей с помощью BCrypt.
### Исправлено
- Исправлена ошибка при обработке путей с обратными слэшами в названиях книг.

## [1.0.1] - 2025-12-25
### Изменено
- Обновлена библиотека Apache Tika для лучшего извлечения метаданных из EPUB файлов.
- Ускорена подгрузка обложек из Google Books за счет кэширования.
### Исправлено
- Исправлено отображение кириллицы в некоторых элементах интерфейса.

## [1.0.0] - 2025-12-01
### Добавлено
- Базовый функционал сканирования книг через Drag & Drop.
- Автоматическая организация файлов по структуре папок (Язык/Жанр/Серия).
- Поддержка форматов PDF, EPUB, FB2, MOBI.
- Светлая и темная темы интерфейса.
