## [1.4.0] - 2026-08-16
### Добавлено
- **Система QR-билетов заказов**:
  - Генерация уникального SHA-256 хеш-токена для каждого заказа книги в физическом магазине.
  - Динамическое создание PNG-изображения QR-кода на основе библиотеки ZXing.
  - Сохранение хешированного токена в колонке `qr_token` таблицы `orders`.
- **Email-уведомления (SMTP)**:
  - Фоновая отправка сообщений с QR-билетом при заказе физической книги на почту пользователя.
  - Настройки отправителя (по умолчанию `kuumuwu@gmail.com`) хранятся в файле `.env` и загружаются автоматически.
- **Просмотр и Скачивание в GUI**:
  - Диалог `OrderQrDialog` с возможностью просмотра и сохранения (`JFileChooser`) PNG-файла QR-кода.
  - Окно «Мої замовлення» с кнопкой «Переглянути QR» для любого имеющегося заказа.
- **Страницы в Веб-интерфейсе**:
  - Страница подтверждения заказа `/order/confirmation/{orderId}` с отображением QR-кода.
  - Роут `/order/{orderId}/qr.png` для выгрузки изображения QR-кода.
  - Отображение QR-кодов в профиле пользователя (`/admin/user/{id}`).
- **Сканирование и проверка (Админка)**:
  - Веб-страница `/admin/scan-qr` для сканирования QR-кода или ввода номера заказа администратором с возможностью быстрой выдачи книги (`DELIVERED`).
  - Кнопка «📷 Сканувати QR / Ввести номер» в диалоге управления заказами в GUI.
- **Тестирование**:
  - Добавлены модульные тесты `QrCodeServiceTest` и `OrderServiceQrTest` для проверки генерации токенов, алгоритмов QR-кодов и бизнес-логики заказов.

## [1.3.0] - 2026-02-02
### Добавлено
- **Веб-интерфейс**: Добавлена возможность просмотра библиотеки через браузер (Javalin + FreeMarker).
- **Docker**: Полная поддержка контейнеризации. Созданы `Dockerfile` и `docker-compose.yml`.
- **Система самоисцеления**:
  - Автоматический выбор свободного порта, если 8080 занят.
  - Повторные попытки подключения к базе данных при старте.
  - Безопасное чтение данных из БД (fallback значения при отсутствии колонок).
- **Магазин и заказы**: Система покупки физических и электронных книг за поинты.
- **Админ-панель**: Управление пользователями, бан-система и статистика базы данных.
- **Автоматизация**: Автоматическое открытие браузера при запуске веб-режима.
- **Headless Mode**: Автоматический запуск веб-сервера при обнаружении безголовой среды (например, Docker).

### Изменено
- Обновлен `Main.java` для выбора режима запуска.
- Улучшена схема базы данных (добавлены таблицы для заказов, уведомлений и черного списка).
- Переработана вся документация проекта.
